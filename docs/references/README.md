## Verification status

The bead counts were gathered with an automated page reader, which summarizes pages and can get numbers wrong. Each file has a **Status** line:

- `unverified`: taken from the summary and not yet checked against the source
- `verified`: checked by hand against the source diagrams

Before we use a pattern as a test fixture, check its counts against the source and change its status to `verified`.

## Counting convention used in these notes

In peyote, the starting ring of N beads forms **rounds 1 and 2 together** (N/2 beads each, since every other bead sits higher). Some sources count it this way; others call the ring "round 0" or "foundation". Each file says which convention the source uses.
