# Research: Commercial Bead Shapes and Sizes

Step 3.1 of [plan.md](plan.md). This file records the shapes and sizes of beads from the three main brands used for peyote: **Miyuki** and **Toho** (Japan) and **Preciosa** (Czech Republic). The bead catalog design in [bead-catalog.md](bead-catalog.md) is based on it.

All sizes are in millimetres.

## 1. Words used here

- **Hole axis:** the line the thread runs along.
- **Outer diameter (width):** the size of the bead across the hole axis. Brands list this as "the size".
- **Length:** the size of the bead along the hole axis. Brands rarely list it.
- **Hole:** the diameter of the hole.
- **Size number (aught, `11/0`):** the traditional size label. A bigger number means a smaller bead. Brands also use mm labels for some shapes (`3mm` cube, `1.5×3mm` bugle).

## 2. Size numbers are not a standard

The same label is a different bead in each brand and product line. For 11/0:

| Bead | Outer diameter | Length | Source |
|---|---|---|---|
| Miyuki Delica (DB) | 1.6 | 1.30 | Official |
| Toho Aiko / Treasure | 1.8 | ~1.5 | Retailers |
| Miyuki Round Rocaille | 2.0 | 1.45 | Official |
| Preciosa Rocaille | 2.0 – 2.2 | not listed | Official |
| Toho Round | 2.2 | ~1.5 | Retailers |

So a pattern that only says "11/0" doesn't tell us the bead's real size. The catalog has to store each brand and product line separately, and keep a generic entry for patterns that don't name a brand.

## 3. Why this matters for peyote

In peyote, the hole axis runs **along the round**. So:

- Each bead takes about its **length** along the round.
- Each new round sits half a bead higher, so the piece grows by about **half the outer diameter** per round.

The ratio of outer diameter to length is very different between shapes:

| Bead | Outer diameter ÷ length |
|---|---|
| Miyuki Delica 11/0 | 1.6 ÷ 1.30 = 1.23 |
| Miyuki Round 11/0 | 2.0 ÷ 1.45 = 1.38 |
| Miyuki Round 15/0 | 1.5 ÷ 1.00 = 1.50 |

This is why the same bead count can lie flat with one bead and cup with another, and why the 15/0 round in the bezel pulls the edge in. It also matches what the 2D diagram needs: each bead should be drawn as a shape that is **length wide and outer diameter tall**, not as a circle.

## 4. Miyuki

Source: Miyuki's official size table ([miyuki-beads.co.jp](https://www.miyuki-beads.co.jp/english/seedbeads/seedgrain.html)). Miyuki says the values are "for reference only" and vary slightly by lot.

The table also gives **beads per 10 cm** of strung beads. We can work out the length from it: length = 100 ÷ beads per 10 cm. Our results for Delica (1.14, 1.30, 1.69, 2.70) match the lengths retailers list (1.15, 1.30, 1.70, 2.70–2.80), so we trust this method.

Notes:

- **Demi Round** is a thin round: same outer diameter and hole as the Round, but much shorter. A useful bead for tight curves.

- **Treasure** comes in two sizes, 1.8 mm (11/0) and 3.3 mm (8/0). Retailers code the 11/0 as `TT-01-<color>`; the 8/0 code is unverified, so the catalog uses `TT-08-<color>`. Toho's chart lists only the 11/0, at 186,300 beads/kg.
- The `?` lengths need to be measured (see section 8).

## 6. Preciosa (Czech)

## 7. Product codes

A bead you buy is a product line, a size and a color. Each brand writes this differently:

| Brand | Example | Parts |
|---|---|---|
| Miyuki Delica | `DB-0010` | Size code (DBS/DB/DBM/DBL) + 4-digit color |
| Miyuki Round | `11-401` | Size + color |
| Toho | `TR-11-49F` | Line (TR = round) + size + color. Seen at retailers |
| Preciosa | `331 19 001` + `23980` | Article number + color code |

The same color number is usually sold in several sizes of a line (Miyuki 401 black exists in 15/0, 11/0 and 8/0). So in the catalog, colors belong to a **line**, not to one size.

## 8. Findings for the catalog design

1. **Store each brand and line separately.** Size labels mean different things in each.
2. **Store both outer diameter and length.** Peyote geometry needs both, and the ratio between them changes the shape.
3. **Store where each number comes from.** Official, retailer, derived or measured. Miyuki is official and complete. Toho has no official mm sizes. Preciosa has official ranges but no length or hole.
4. **Allow ranges.** Czech sizes are ranges. Japanese sizes are single values.
5. **Separate geometry from color.** One size of a line has one geometry and many colors.
6. **Keep a generic entry per shape and size** for patterns that don't name a brand.
7. **Shapes:** for peyote we need cylinder, round, demi round, cut round (charlotte, 3-cut), hex, triangle, cube and bugle. All have one hole along the center. Drops, magatamas, tilas and other shapes with off-center or two holes can wait, but the design should leave room for them.
8. **Measure the gaps.** Toho lengths and Preciosa lengths and holes are missing. Measuring 10 cm of strung beads (or counting beads per 10 cm, as Miyuki does) is a cheap way to fill them in.
9. **Beads per gram** gives the shopping list in grams, which is how Japanese beads are sold.
